# ОМА VIBE — дополнительный режим iOS и PWA

Ветка: feature/oma-vibe-mode, ответвлена от feature/oma-brand-ui.

Статус: неофициальный конкурсный концепт. AI-преображение загруженной комнаты и реальные платежи не реализованы. Изображения VIBE — синтетические целевые интерьерные рендеры, не реальные сканы квартир.

## Вход
- iOS: Главная → ОМА · VIBE. Режим хранится в UserDefaults (oma_vibe_enabled); возврат кнопкой «Обычный ОМА».
- Веб: Главная → «Включить VIBE» или URL /?view=vibe. Полностью отдельная адаптивная тема public/vibe.css, возврат кнопкой «Обычный ОМА».
- Каталог и корзина общие. iOS использует единый Store и SavedProject, VIBE-проект отображается в нативном разделе проектов. Веб хранит собственный VIBE-черновик лишь в localStorage, НЕ в серверных проектах; корзина остаётся общей серверной.

## Дизайн и данные
Палитра — индиго #302B7B, бирюза #13ADC2, коралл #FF7058, кремовый #F7F5F0. Используются повторно синтетические интерьерные изображения из ветки feature/oma-finance-banking, работающие локально/offline.
Список продуктов VIBE использует реально присутствующие в демо-каталоге позиции p18/p20 и их синтетические цены, а не суммы из AIDesigner.
ZeroBuy уменьшает только предварительную смету при отметке «уже есть». Он не удаляет товар из существующей корзины автоматически. Монтаж, инженерная совместимость и техническая безопасность не подтверждены.

## Локальная проверка на Mac
Команды:
- npm ci
- npm run typecheck
- npm run test:proof
- npm test
- npm run test:e2e
- xcodebuild -project ios/OMAOne.xcodeproj -scheme OMAOne -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build

Проверьте вручную:
1. Кнопку Classic → VIBE → Classic и сохранение выбора при повторном открытии iOS.
2. Общую корзину в обоих режимах и возврат к проектам.
3. URL /?view=vibe и мобильную ширину 320, 375 и 390px.
4. Отображение локальных изображений offline после первого успешного визита.
5. Dynamic Type/VoiceOver/Reduce Motion, точность предупреждений и разделение прототипа/продукта.

Это список необходимых проверок, не утверждение о том, что тесты уже пройдены.
