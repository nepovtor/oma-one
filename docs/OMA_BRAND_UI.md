# ОМА — единый дизайн приложения и веб-прототипа

**Статус:** неофициальный конкурсный концепт. Использование оригинального логотипа в прототипе не означает разрешения торговой сети ОМА на выпуск приложения.

## Что изменено

- Видимое название продукта **ОМА** (без ONE), пользовательское название iPhone-приложения — **«ОМА · Дом»**.
- В iOS и браузере используется один исходный логотип: `ios/OMAOne/Assets.xcassets/OMALogoReference.imageset/OMALogoReference.jpg` и `public/icons/oma-logo.jpg`.
- Из корпоративных материалов адаптированы основные цвета: индиго **#302B7B**, бирюзовый **#13ADC2**, фон **#F5F6FB**, белые карточки.
- iOS: новая домашняя, контрастный сценарий установки полки, заметный вход в 3D-квартиру, единые карточки и нижняя навигация.
- Веб: фирменный хедер, оригинальный знак вместо нарисованной иконки, адаптивный главный экран, кнопки, карточки, фокусные и мобильные состояния.
- Лаборатория расчётов: фирменный стиль и имя ОМА при неизменных вычислениях.
- PWA: новый ярлык, SVG-пиктограмма с исходным логотипом и обновлённый офлайн-кэш.

## Совместимость

Технические имена `ONEHub`, `ONEFeature`, `OMAOne.xcodeproj`, API `/api/v1`, ключи локальных хранилищ и имена алгоритмов оставлены без изменений. Они не отображаются как название сервиса, но их переименование без отдельной миграции сломало бы сохранённые проекты.

## Проверка на Mac

```bash
git fetch origin
git switch feature/oma-brand-ui
git pull --ff-only origin feature/oma-brand-ui
npm ci
npm run typecheck
npm run test:proof
npm test
npm run test:e2e
npm run check:ios-evidence
xcodebuild -project ios/OMAOne.xcodeproj -scheme OMAOne -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

Откройте сайт и проверьте отображение на ширине 320, 375, 768 и 1440 px: контраст и доступность кнопок с клавиатуры, отсутствие горизонтальной прокрутки, ссылку на корзину, сохранение полки и офлайн-запуск после первого подключения.

В Xcode проверьте главную, каталог, корзину, запуск полки, Proof и 3D-квартиру. На физическом iPhone необходим отдельный ручной прогон.

## Границы

- Прототип неофициальный. Право публично распространять логотип ОМА и точные актуальные нормы брендбука не подтверждены.
- Нет подтверждённой интеграции с реальными покупками, бонусами или мастерами.
- Сайт не заявляет нативную 3D-квартиру как доступную в браузере. 3D остаётся в iOS.
- Результаты последних проверок и сборки должны фиксироваться реальными логами, а не предполагаться.
