# P1: единые расчётные контракты

`proof-engine.ts` — единственный исходник демонстрационных правил. PWA получает сгенерированный браузерный бандл при `npm run build`, iOS — `ios/OMAOne/evidence-engine.js` через `npm run build:ios-evidence`, backend импортирует функции напрямую.

## Сценарий полки

Контракт `shelfDecision` объединяет AntiFail, ZeroBuy, Domino и Proof. Одинаковый JSON-вход даёт одинаковый результат в Node.js, браузерном бандле и JavaScriptCore на iOS. Клиентские адаптеры отвечают только за преобразование состояния экрана и отображение результата.

## Proof

Допустимая последовательность статусов:

```text
IN_PROGRESS → SELF_REPORTED → EVIDENCE_SUBMITTED → EXPERT_VERIFIED
             └──────────────→ EVIDENCE_SUBMITTED
```

- `POST /api/v1/projects/:id/complete` сверяет checklist и `stepIds` с полным сохранённым планом, повторно проверяет Domino и создаёт `SELF_REPORTED` без фото либо `EVIDENCE_SUBMITTED` с сохранённым фото.
- `POST /api/v1/projects/:id/verify` доступен только роли `master`, принимает только полную `EVIDENCE_SUBMITTED` запись и создаёт `EXPERT_VERIFIED`.
- Фото, хеш и самостоятельная отметка сами по себе не дают экспертный статус.
- `/api/v1` сохранён; `stepIds` добавлен как обратносуместимое поле. Миграция `004_proof_statuses.sql` дополняется корректирующей `005_proof_legacy_guard.sql`: историческое фото или флаг `expert` сами по себе не повышают статус. При недостатке подтверждений запись остаётся `SELF_REPORTED`. Новый `EVIDENCE_SUBMITTED` сохраняется только при полном чек-листе и хешах фото/записи, а `EXPERT_VERIFIED` — дополнительно при идентификаторе и времени проверки специалиста.

## Остальные механизмы

- SyncCity: `/groups/:id/join` проверяет совместимость города, района, слота и услуги; экономику возвращает канонический `syncCity`.
- OMA DNA: `/dna/match` ранжирует и адаптирует площадь через `dna`; сходство не становится гарантией применимости.
- OMA FORGE: голос и решение менеджера возвращают `forge`; интерес остаётся предложением, цена не публикуется автоматически.
- OMA PULSE: повторный отчёт одного пользователя по той же модели и категории отклоняется; сигнал строится только из независимо подтверждённых записей и не отправляет внешних уведомлений.

Контрактный тест `tests/evidence-contracts.test.ts` сравнивает все восемь механизмов на негативных входах в Node.js, PWA-бандле и iOS-бандле.
