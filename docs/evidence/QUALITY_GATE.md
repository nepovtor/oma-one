## Не подтверждено — не заявлять на защите как факт

| Проверка | Статус | Почему / что нужно |
|---|---|---|
| Xcode build на iPhone | **Не проверено** | Только Mac с Xcode и устройством/симулятором |
| Связь SwiftUI со сквозным производственным backend | **Не завершена** | Локальная iOS-демонстрация и лаборатория — разные контуры |
| Интеграционные тесты production API с PostgreSQL | **Не проверено в данной среде** | Нужны PostgreSQL, зависимости, проверка окружения и авторизации |
| Реальная интеграция с приложением и корзиной ОМА | **Нет** | Требуется API, разрешение ОМА и IMSHOP.IO |
| Реальные покупатели, заказы, цены и остатки | **Нет** | Доступ к данным ОМА, пользовательский пилот |
| Реальная точность строительных рекомендаций | **Нет** | Независимый инженерный эксперт и утверждённые правила |
| Экономический эффект, CAC, ROI, retention | **Нет** | Контрольное исследование и внутренние данные компании |
| Консольный/браузерный визуальный тест в этой среде | **Ограничен** | Графический браузер блокирует localhost, проверены HTML/JS и API |

## Вывод

Это **более доказуемый инженерный MVP**, не production-ready сервис. Механизмы реально вычисляют решения по заданным входам и сохраняют подробный поясняющий след, но реальные выгоды клиентам и коммерческая применимость пока **гипотезы**.

Для защиты демонстрировать безопасную полку и смету на тестовых данных + результаты проверок. Не использовать формулировки «проверен на покупателях ОМА», «экономия доказана», «всё подключено», «инженерная безопасность гарантирована».
