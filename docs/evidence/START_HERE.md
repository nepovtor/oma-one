# OMA ONE — старт для технической проверки перед презентацией

## Самая простая проверка без Docker, PostgreSQL и внешнего AI

**На Mac/Linux:** двойной запуск через терминал `bash RUN_EVIDENCE_MAC_LINUX.sh`.
**На Windows:** `RUN_EVIDENCE_WINDOWS.cmd`.

Или вручную:

```bash
npm run test:proof
npm run evidence
```

Затем откройте **http://localhost:8790** на Mac/ПК. На iPhone в одной Wi-Fi сети откройте `http://IP-адрес-Mac:8790/proof.html`. Встроить страницу внутрь SwiftUI: в разделе «Профиль → Моя информация» укажите этот URL в поле «URL лаборатории» и затем нажмите в OMA ONE кнопку «Проверить расчёты».

**Тестовый порт 8790 — отдельная лаборатория.** Он не обращается к базе клиентов ОМА, не принимает платежи, не изменяет реальные товары и не поднимает production API. Сервер доступен в локальной сети — для публичного интернета использовать нельзя без проверки безопасности.

## Что проверить руками на сцене

| Модуль | Измените | Ожидаемое поведение |
|---|---|---|
| ZeroBuy | Лента дома: 1 → 0 | Смета покупки вырастет на 6,9 BYN |
| AntiFail | Гипсокартон → бетон (при бетонном крепеже) | BLOCKED сменится на REVIEW при непроверенной проводке |
| Domino | Плитка до гидроизоляции: да → нет | Ошибочный граф станет допустимым |
| SyncCity | Общий выезд 48 → 100 BYN | Пропадёт положительная экономия |
| Proof | Отметьте независимую проверку и согласие | Только тогда DNA может получить запись |
| DNA | Площадь 4 → 8 м² | Пересчёт количества; сопоставление падает |
| FORGE | Порог спроса 4 → 5 | Комплект-кандидат становится недостаточно подтверждённым |
| PULSE | Отключите подтверждение третьего случая | Сигнал перестанет соответствовать порогу |
| Economics | Увеличьте привлечение до 200 BYN | Вклад заказа станет отрицательным |

## Откуда берётся «доказательство»

`proof-engine.ts` содержит исполняемые правила, `proof-fixtures.ts` — искусственные входные данные, `tests/proof-engine.test.ts` — позитивные и негативные кейсы, `docs/evidence/OUTPUT_TRACES.json` — реальные ответы функций, `docs/evidence/EXECUTION_REPORT.md` — автоматически сформированная сводка.

## Что не доказывается кодом

Оценки рынка, настоящие пользователи, рост выручки, точность инженерных выводов, скидки поставщиков и интеграция с живыми системами ОМА. Для этого существует `USER_VALIDATION_PROTOCOL.md`; до сбора фактов выдавать гипотезы за результаты нельзя.
