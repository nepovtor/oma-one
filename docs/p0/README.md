# P0 — продуктовая и интеграционная готовность

Дата среза: **22 октября 2026 года**.

Этот каталог — рабочий пакет решений до production-разработки OMA ONE. Принято исходное допущение: все заявленные модули, мастера, фото Proof и внешний AI разрешены для production-пилота. Их бизнес-эффект, качество и SLO всё ещё проверяются на пилоте.

## Статус

| Область | Статус | Что уже сделано | Что блокирует закрытие |
|---|---|---|---|

## Ворота перехода к P1

P1 production-разработка не начинается, пока одновременно не выполнены условия:

- D-01…D-07 приняты по исходному допущению; до реального запуска они заменяются именами владельцев и ссылками на артефакты;
- получены версионированные контракты обязательных API и доступ в sandbox;
- для каждого сценария зафиксированы утверждённые экспертные источники, правила и критерии тестов;
- назначены владельцы правил, каталога, инцидентов и пользовательской поддержки;
- операционные и технические контроли из `06-legal-risk-assessment.md` перенесены в backlog с владельцами;
- измеримые критерии приёмки из `03-scenarios-sla-acceptance.md` приняты обеими командами.

До получения реальных API-контрактов и sandbox допустимы прототипирование и integration spikes; production-трафик не включается.
