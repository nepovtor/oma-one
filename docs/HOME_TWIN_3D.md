# OMA HOME TWIN — квартира по пользовательскому плану 58,67 м²

Нативный экспериментальный модуль OMA ONE на ветке `feature/oma-home-twin-3d`. Это неофициальный демонстрационный прототип. Он не сканирует квартиру и не заменяет обмер, проект или техническую проверку.

## План

Схема восстановлена по присланному изображению низкого разрешения. Площади взяты с изображения; часть линейных размеров вычислена приблизительно и помечена знаком `≈`.

| Помещение | Размер для визуализации | Площадь по схеме |
| --- | ---: | ---: |
| Гостиная | 3 240 × 5 560 мм | 18,00 м² |
| Кухня | 2 830 × 2 340 мм | 6,62 м² |
| Ванная | ≈ 2 040 × 1 035 мм | 2,11 м² |
| Туалет | ≈ 1 770 × 590 мм | 1,04 м² |
| Г-образный коридор | составной контур | 7,04 м² |
| Спальня | ≈ 3 190 × 4 260 мм | 13,58 м² |
| Вторая комната / кабинет | ≈ 2 850 × 3 610 мм | 10,28 м² |

Сумма площадей — 58,67 м². Небольшие промежутки на размерной схеме обозначают стены. Эти данные нельзя использовать для закупки материалов или строительных работ без фактического обмера.

## Визуализация

Старая примитивная SceneKit-геометрия удалена. В приложение встроены восемь оптимизированных JPEG-рендеров: общий «кукольный» вид и отдельный интерьер каждого помещения. Вся квартира оформлена в единой стилистике пользовательского референса: глубокий зелёный, оливковый текстиль, тёплый орех, бежевый камень, растения и многослойный тёплый свет.

Рендеры созданы как синтетическая дизайн-концепция. Они выглядят как интерьерные фотографии, но не являются фотографиями фактической квартиры, фотограмметрией или гарантией результата. Изображения работают полностью локально, поддерживают увеличение, перемещение и двойное касание для быстрого масштаба.

Скриншоты фактически запущенного приложения на iPhone 17 Pro Simulator: [вся квартира](home-twin-screenshots/overview-photorealistic-iphone17pro-simulator.png) и [интерьер гостиной](home-twin-screenshots/interior-photorealistic-iphone17pro-simulator.png).

Режим «Готовый вид» показывает целевой синтетический рендер. Режим «К прогрессу» показывает личное фото выбранной комнаты, если пользователь его добавил. Без личного фото целевой рендер затемняется пропорционально записанному проценту и прямо обозначается как условная индикация, а не текущее состояние.

Этапы, фото комнаты и связь с проектом полки сохраняются локально. Данные предыдущих `oma_home_twin_3d_v1` и `v2` мигрируют в новый ключ `oma_home_twin_photo_v3`; новая отдельная туалетная комната начинает без отметок. Proof влияет на процент выбранной комнаты, но не подтверждает качество работ специалистом.

## Мобильность

Каждый рендер уменьшен до максимальной стороны 1600 px и сохранён в JPEG с размером примерно 300–500 КБ. Экран не загружает сеть и не создаёт тяжёлую трёхмерную сцену, поэтому памяти и GPU требуется заметно меньше, чем для детальной 3D-модели. Физическая проверка на iPhone 12 Pro/Max всё ещё обязательна перед заявлением о стабильной производительности.

## Проверка

```bash
npm run test:proof
xcodebuild -project ios/OMAOne.xcodeproj -scheme OMAOne -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

В Simulator: Главная → «Моя квартира · фото». Проверить общий вид, затем открыть каждую карточку помещения и масштабировать изображение. Переключить «К прогрессу», добавить личное фото, изменить четыре этапа и проверить процент. Перезапустить приложение и убедиться, что отметки и фото сохранились. Отдельно проверить состояния Proof `PLANNED`, `SELF_REPORTED` и `EVIDENCE_SUBMITTED`.
