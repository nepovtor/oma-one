# P2 — интерфейс

Статус на 22.10.2026: интерфейсный baseline готов и проверен локально в desktop-режиме и адаптивном viewport 390×844.

## Реализовано

- Основная навигация сокращена до главных сценариев: главная, решение задачи, каталог и проекты. Восемь расширенных модулей и служебные разделы перенесены на экран «Ещё».
- Добавлены отдельные loading, empty, offline и fatal error states, повтор загрузки и индикаторы занятости.
- Уведомления на мобильном перенесены вверх, чтобы они не перекрывали нижнюю навигацию.
- Добавлены skip link, семантические `nav/header/main`, `aria-current`, связка подписей с полями, управление фокусом после навигации, доступный dialog с focus trap и закрытием по Escape.
- Учтены `prefers-reduced-motion` и forced/high contrast; увеличены мобильные интерактивные зоны.
- Навигация синхронизирована с history и параметром `?view=`, поэтому системные Back/Forward работают предсказуемо.
- Подготовлены PNG-иконки 192/512 px и Apple Touch icon, installable manifest и offline service worker.
- Добавлена минимальная продуктовая аналитика: только разрешённые события и типизированные свойства, без произвольного пользовательского текста.
- Добавлена статическая проверка UI-примитивов и API-тест аналитики.

## Проверка

- `npm test`: 11/11 тестов проходят.
- `node --check`: клиент, service worker и сервер проходят проверку синтаксиса.
- Manifest проходит JSON-валидацию.
- Визуально проверены desktop и 390×844; экран «Ещё» и мобильная нижняя навигация работают.
- После обновления service worker ошибок приложения в консоли нет. Предупреждения установленного браузерного расширения не относятся к OMA ONE.
