# OMA ONE — iPhone, конкурсная версия

## Интерфейс iPhone

- Главная: логотип, выбор города, поиск и короткий путь к OMA ONE, каталогу и корзине.
- Каталог: только категории с демонстрационными товарами, поиск, список всех товаров, карточка товара с подробностями, добавление в корзину и избранное.
- Нижняя навигация: **Главная / Каталог / Корзина / Избранное / Профиль**. На iOS 26 используется Liquid Glass; при уменьшении прозрачности — непрозрачные поверхности.
- Корзина: пустое состояние, управление количеством, согласованный итог, подтверждение **демо-заказа** (реального платежа нет).
- Избранное: сохранение товаров на устройстве.
- Профиль: данные демонстрационного покупателя, история демо-заказов, город, настройки внешнего сервера и честное описание прототипа.
- Встроенный раздел **OMA ONE**: путь «задача → ограничения → смета → корзина» и доступ ко всем восьми модулям. Основные сценарии доступны **без интернета**.
- Версия 1.2: мягкий визуальный отклик кнопок и вкладок, анимированные счётчики корзины, короткое «Добавлено» на товаре и подтверждение комплекта перед переходом в корзину. Звуки и вибрация не используются; при «Уменьшении движения» масштабирование и переходные анимации отключаются.

### OMA HOME TWIN — интерактивная 3D-квартира (эксперимент)

В отдельной ветке `feature/oma-home-twin-3d` добавляется нативная сцена SceneKit: личная схематичная квартира с 1–4 комнатами, ручными размерами, фото-ориентирами и этапами ремонта. Стены, пол, освещение и мебель меняются визуально по вашим отметкам. Запись Proof по полке автоматически влияет на её появление в 3D, но **не подтверждает качество работ специалистом**. Режим просмотра желаемого результата не меняет реальный прогресс. Подробные инструкции — [docs/HOME_TWIN_3D.md](docs/HOME_TWIN_3D.md).

### Золотой сценарий: повесить полку

Главная теперь начинается с вопроса «Что хотите сделать дома?». По кнопке «Хочу повесить полку» открывается единый офлайн-проект: материал стены, вес полки и планируемая нагрузка, выбранный крепёж, три критические проверки, состав покупок с учётом вещей дома, порядок работ и фото результата. Черновик можно сохранить в любой момент и продолжить в «Мой дом» или с главной после перезапуска приложения. Он хранится в `UserDefaults` на устройстве, фото — локально в Documents.

AntiFail исключает несовместимый крепёж и предлагает заменить бетонный дюбель на демо-анкер для гипсокартона с повторной проверкой. При неизвестной стене, непроверенных условиях, нагрузке больше демонстрационного порога или отсутствии подходящего товара комплект не формируется. Даже «предварительный вариант» **не считается сертифицированным безопасным монтажом**. ZeroBuy вычитает только количества, которые пользователь сам отметил как имеющиеся дома; Domino проверяет порядок этапов; Proof после всех обязательных шагов разрешает запись **SELF_REPORTED** без фото либо **EVIDENCE_SUBMITTED** с локальным фото и его хешем. Ни одна из этих отметок не считается проверкой специалиста.

У каждого из 28 демо-товаров теперь отдельная локальная сгенерированная иллюстрация. Ни картинки, ни цены, ни остатки не являются реальными карточками или данными ОМА. Происхождение и промпт ассетов описаны в `docs/golden-flow-assets.md`.

Визуальная ревизия выполнена по Taste Skill, направлению `pastel-consumer` (seed `850841195`): компактная иерархия, светлые категории и заметное основное действие. Синий цвет OMA ONE и Liquid Glass сохранены как требования этого концепта; браузерный инспектор скилла к нативному SwiftUI не применяется, поэтому экраны проверяются в iOS Simulator.

### Восемь функций OMA ONE

| Модуль | Что можно выполнить на iPhone в демо |
| --- | --- |
| ZeroBuy | Отметить домашние запасы и исключить их из сметы |
| AntiFail | Сменить материал стены и обнаружить конфликт крепежа |
| Domino | Поменять порядок этапов и получить объяснимое предупреждение |
| SyncCity | Присоединиться к тестовой группе соседей, выйти из неё |
| Proof | Отметить выполнение со слов пользователя без фото либо приложить фото для доказательной записи; экспертного статуса нет |
| OMA DNA | Адаптировать образец проекта к площади и сохранить |
| OMA FORGE | Подтвердить интерес к созданию товарного комплекта |
| OMA PULSE | Включить/отключить наблюдение по условному случаю неисправности |

Всё это **симулированные бизнес-сценарии**, не реальные заказы/скидки/ошибки продуктов/сообщения соседей.

## Запуск на iPhone

Нативные экраны используют локальный JavaScriptCore-мост к проверяемым правилам из `proof-engine.ts`. После изменения правил пересоберите встроенный файл командой `npm run build:ios-evidence`; `npm run check:ios-evidence` проверяет, что он не устарел. Кнопка «Рассчитать локально» в каждом из восьми модулей показывает результат и исходные ограничения без сети. Для ZeroBuy, AntiFail, Domino и DNA используются текущие параметры экрана; остальные модули запускают явно обозначенный синтетический пример.

1. На Mac установите Xcode (проект рассчитан на iOS 16 и новее).
2. Откройте `ios/OMAOne.xcodeproj`.
3. В разделе проекта **OMAOne → Signing & Capabilities** выберите собственную команду Apple Development и при необходимости задайте уникальный Bundle Identifier. Чужая команда разработчика из исходного архива удалена.
4. Подключите iPhone, разблокируйте, разрешите Developer Mode, выберите iPhone в селекторе устройства.
5. Нажмите ▶ **Run**. Нативные экраны откроются **без сервера**.

При запуске на физическом устройстве Xcode может потребовать доверить сертификату разработчика. Это стандартная процедура локальной сборки, не публикация в App Store.

## Запуск полного дополнительного серверного движка

Backend и PWA из присланного проекта сохранены без миграции функциональности в другое приложение. В корне проекта на Mac:

```bash
npm install
npm run db:up
export DATABASE_URL='postgresql://oma:oma@127.0.0.1:55432/oma_one'
npm start
```

На iPhone откройте **Профиль → Моя информация**, введите `http://АДРЕС_MAC_В_СЕТИ:8787` (например `http://192.168.1.20:8787`), затем выберите «Открыть расширенный веб-движок». Телефон и Mac должны быть в одной сети, порт должен быть доступен с телефона. **Не используйте `localhost`** на iPhone: это сам телефон, а не Mac.

Это опциональное подключение: встроенные функции работают без сервера. Для production требуется HTTPS, доступы API ОМА и аудит безопасности.

## Проверка сборки

На Mac с Xcode:

```bash
xcodebuild -project ios/OMAOne.xcodeproj -scheme OMAOne -configuration Debug -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

Проверяйте после каждого изменения в Xcode и в симуляторе. Сборка и скриншоты симулятора не заменяют проверку на физическом iPhone.

Автотесты офлайн-правил и модели проекта: `npm run test:proof`. Тесты включают успешный, заблокированный и незавершённый путь полки, восстановление Codable-черновика и наличие 28 локальных иллюстраций. Скриншоты ключевых экранов iPhone Simulator находятся в `docs/golden-flow-screenshots/`.

## Для настоящей интеграции с ОМА

- Официальный API товаров: SKU, фотографии с правами использования, варианты крепежа, актуальные цены и остатки по городу.
- Утверждённые инженером правила совместимости для материалов стен, нагрузки, крепежа и инструкций производителей; путь к специалисту при неопределённости.
- Авторизация и синхронизация проектов между устройствами с миграцией локальных черновиков.
- Согласие пользователя, политика хранения/удаления фотографий и отдельная процедура экспертной проверки, если она будет заявлена.
- Реальные корзина, резервирование, доставка и платёжная интеграция только после согласования с ОМА; сейчас заказ исключительно демонстрационный.

## Юридические рамки

Это **неофициальный конкурсный прототип**, не замена выпущенного приложения ОМА и не интеграция с системами торговой сети. Фотографии промобаннеров и части категорий вырезаны из **скриншотов, предоставленных пользователем**; используйте эти изображения **только в закрытой демонстрации** до согласования прав и разрешения ОМА. Приложение не вводит реальные платёжные данные. Официальные поставщики, цены, группы, AI-анализ и уведомления не подключены.


## Проверяемые алгоритмы (новое)

Запусти `npm run evidence` на Mac, подключи iPhone к той же Wi-Fi сети и впиши в профиле в поле «URL лаборатории» адрес `http://<IP-Mac>:8790/proof.html`. В OMA ONE появится переход в интерактивную лабораторию 8 технологий и экономики. Эта часть работает с синтетическими данными, независимо от серверной базы. При отсутствии сети остаются нативные демо-экраны. Референс: `docs/evidence/START_HERE.md`.

**Ограничение:** данные каталога, расчёты и заказы остаются демонстрационными; права на исходные изображения из пользовательских скриншотов и реальные интеграции нужно подтвердить отдельно.
